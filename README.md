# PRIMECUT — сайт агентства продвижения

Тёмный сайт с анимациями: огромный заголовок PRIMECUT, объектив, который тянется за курсором, бегущие ленты работ, текст «О нас», проявляющийся по буквам, карточки проектов, которые складываются стопкой при прокрутке, каталог специалистов и формы заявки.

Все файлы лежат рядом, без папок. Ничего устанавливать не нужно.

## Файлы сайта

```
index.html     весь текст сайта
styles.css     оформление: цвета и шрифты — в начале файла
main.js        анимации и формы — трогать не нужно
config.js      список работ для бегущих лент и настройки заявок
privacy.html   политика конфиденциальности (шаблон)
404.html       страница «не найдено»
favicon.svg    иконка вкладки
```

## Как добавить свои картинки — без правки кода

Загрузите картинку в репозиторий (кнопка «+» → «Upload files») с ТОЧНО таким названием, как в таблице. Сайт сам подставит её вместо заглушки. Пока файла нет, на его месте стоит встроенная картинка или цветной градиент.

| Название файла | Где появится | Совет |
|---|---|---|
| `hero.png` | Первый экран, вместо объектива | PNG с прозрачным фоном, около 1000×1000 |
| `work-01.jpg` … `work-12.jpg` | Бегущие ленты работ | Горизонтальные, около 840×540 |
| `deco-1.png` … `deco-4.png` | Четыре картинки вокруг «О нас» | PNG с прозрачным фоном, около 400×400 |
| `project-1-1.jpg` | Проект 01, левое верхнее фото | |
| `project-1-2.jpg` | Проект 01, левое нижнее фото | |
| `project-1-3.jpg` | Проект 01, правое высокое фото | Вертикальное |
| `project-2-…`, `project-3-…` | То же для проектов 02 и 03 | |

Важно:

- Названия — латиницей, маленькими буквами, без пробелов.
- Windows может прятать окончание файла. Включите «Просмотреть» → «Показать» → «Расширения имён файлов», чтобы файл не назывался случайно `hero.png.png` или `work-01.jpeg`.
- Для бегущих лент подойдут GIF или короткие видео MP4. Тогда в `config.js` поменяйте окончание в списке `works`, например `"work-03.mp4"`. Видео лучше делать лёгкими — до 5 МБ.
- Хотите больше или меньше работ в лентах — допишите или удалите названия в списке `works` в `config.js`.

## Как поменять текст

Откройте `index.html` на GitHub → карандаш → Ctrl+F, найдите текст → поменяйте только то, что между значками `>` и `<` → «Commit changes». `&nbsp;` — это пробел, который не даёт строке разорваться; его можно оставить.

- Специалист — блок от `<article class="pro"` до `</article>`. Скопируйте блок, чтобы добавить ещё одного; удалите целиком, чтобы убрать. `data-category`: `video`, `edit` или `smm`.
- Ссылка на портфолио или проект: замените `href="#"` на настоящую ссылку. Пока стоит `#`, кнопка на сайте не показывается.

## Заявки

Сейчас форма копирует текст заявки и открывает Telegram агентства (`telegram` в `config.js`). Чтобы заявки приходили на почту автоматически, создайте форму на formspree.io и вставьте её адрес в `endpoint` в `config.js`.
