# PRIMECUT — сайт агентства продвижения (светлая версия)

## Идея сайта: «Путь кадра»

Через весь сайт летит 3D-фотоаппарат — как агентство, которое ведёт проект от первого кадра до публикации. На первом экране он крутится крупно, дальше уменьшается и сопровождает каждый раздел, а в «Контактах» делает вспышку. После отправки заявки — ещё одна вспышка.

Разделы по порядку:

1. **Первый экран** — «Снимаем. Монтируем. Продвигаем», цифры и кнопка заявки.
2. **Ленты кадров** — работы едут в разные стороны и наклоняются при прокрутке.
3. **О нас** — текст проявляется по словам, вокруг крутятся полароиды с людьми.
4. **Путь проекта** — страница «едет» вбок: Съёмка → Монтаж → Публикация → Результат, в каждом шаге своя анимация.
5. **Услуги** — карточки наклоняются и переворачиваются при прокрутке.
6. **Специалисты** — карточки людей переворачиваются по нажатию: на обороте цена и кнопка «Выбрать».
7. **Плёнка** — лента кадров пересекает страницу.
8. **Проекты** — карточки складываются стопкой.
9. **Контакты** — заявка для клиентов и анкета для специалистов.

## Файлы

```
index.html     весь текст сайта
styles.css     оформление: цвета и шрифт — в начале файла
main.js        анимации, фотоаппарат и формы — трогать не нужно
config.js      список работ, фотоаппарат вкл/выкл, настройки заявок
privacy.html   политика конфиденциальности (шаблон)
404.html       страница «не найдено»
favicon.svg    иконка вкладки
```

## Свои фото и видео — без правки кода

Загрузите файл в репозиторий («+» → «Upload files») с ТОЧНО таким названием. Сайт сам поставит его вместо заглушки.

| Название файла | Где появится | Совет |
|---|---|---|
| `hero.mp4` | Видео на фоне первого экрана | Светлое, до 10 МБ, без звука |
| `work-01.jpg` … `work-12.jpg` | Ленты кадров | Горизонтальные, около 760×500 |
| `people-1.jpg` … `people-4.jpg` | Полароиды в «О нас» | Вертикальные 4:5, фото людей в работе |
| `pro-1.jpg` … `pro-6.jpg` | Фото специалистов по порядку карточек | Вертикальные, лицо по центру |
| `project-1-1.jpg`, `-1-2`, `-1-3` | Фото проекта 01 (третье — высокое) | |
| `project-2-…`, `project-3-…` | То же для проектов 02 и 03 | |

- Названия — латиницей, маленькими буквами, без пробелов.
- Включите в Windows «Просмотреть» → «Показать» → «Расширения имён файлов», чтобы проверить, что файл называется именно `pro-1.jpg`, а не `pro-1.jpg.jpg` или `pro-1.jpeg`.
- В ленты кадров можно GIF или короткие MP4 — поменяйте окончание в списке `works` в `config.js`.

## Как поменять текст

`index.html` на GitHub → карандаш → Ctrl+F → меняйте только текст между `>` и `<` → «Commit changes». `&nbsp;` — неразрывный пробел, его можно оставить.

- Специалист — блок от `<article class="person"` до `</article>`. Скопируйте целиком, чтобы добавить; удалите целиком, чтобы убрать. `data-category`: `video`, `edit` или `smm`.
- Ссылки «Портфолио» и «Смотреть проект»: замените `href="#"` на настоящую ссылку. Пока стоит `#`, кнопки не видно.
- Цифра «+6 специалистов» считается сама по количеству карточек.

## Заявки

Сейчас форма копирует текст заявки и открывает Telegram (`telegram` в `config.js`). Чтобы заявки приходили на почту, создайте форму на formspree.io и вставьте её адрес в `endpoint` в `config.js`.
