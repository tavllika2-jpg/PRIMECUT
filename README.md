# PRIMECUT — сайт агентства продвижения

Сайт агентства: услуги (видеосъёмка, монтаж, SMM), каталог специалистов с фильтром, форма заявки для заказчиков и анкета для специалистов, которые хотят попасть в каталог.

Сделан на обычных HTML, CSS и JavaScript. Ничего устанавливать не нужно: файлы можно править прямо на сайте GitHub, и изменения появятся на сайте через 1–2 минуты.

## Что где лежит

Все файлы лежат рядом, без папок:

```
index.html     весь текст сайта: услуги, специалисты, этапы работы, формы, контакты
privacy.html   политика конфиденциальности (шаблон)
404.html       страница «не найдено»
styles.css     оформление: цвета и шрифт — в самом начале файла
config.js      куда приходят заявки: Telegram или адрес Formspree
main.js        как работает сайт (фильтр, формы, анимация) — трогать не нужно
favicon.svg    иконка вкладки
```

## Как поменять текст на GitHub

1. Откройте в репозитории файл `index.html`.
2. Нажмите на значок карандаша справа сверху (Edit this file).
3. Нажмите Ctrl+F (на Mac — Cmd+F) и найдите текст, который хотите поменять.
4. Меняйте только текст между значками `>` и `<`. Сами значки, кавычки и слова на английском не трогайте.
5. Нажмите зелёную кнопку «Commit changes», затем ещё раз «Commit changes» в окошке.

`&nbsp;` в тексте — это пробел, который не даёт строке разорваться в неудачном месте, например между числом и «₽». Его можно оставить как есть или заменить обычным пробелом.

## Как добавить или убрать специалиста

В `index.html` найдите раздел «КАТАЛОГ СПЕЦИАЛИСТОВ». Каждый специалист — это блок от `<article class="pro"` до `</article>`.

- Чтобы добавить: скопируйте целиком любой блок и вставьте ниже, затем поменяйте имя, описание и цену.
- Чтобы убрать: удалите блок целиком, от `<article` до `</article>` включительно.
- `data-name="…"` — имя, которое попадёт в заявку. Пишите его так же, как в заголовке карточки.
- `data-category="…"` — направление: `video` (съёмка), `edit` (монтаж) или `smm` (SMM и продвижение). От него зависит цвет полоски и фильтр.
- Портфолио: замените `href="#"` на ссылку, например `href="https://t.me/channel"`. Пока стоит `#`, ссылка на сайте не показывается.

Список специалистов в форме заявки обновится сам.

## Как принимать заявки

Сейчас форма копирует текст заявки и открывает Telegram агентства — клиенту остаётся вставить текст и отправить. Имя Telegram-аккаунта указано в `config.js` в строке `telegram: "primecut_agency"`.

Чтобы заявки приходили на почту автоматически:

1. Зарегистрируйтесь на formspree.io и создайте форму.
2. Скопируйте адрес вида `https://formspree.io/f/xxxxxxx`.
3. Вставьте его в `config.js` в кавычки после `endpoint:`.

## Публикация

Репозиторий должен быть публичным (Public). Затем: Settings → Pages → Source: «Deploy from a branch» → ветка `main`, папка `/ (root)` → Save. Через пару минут сайт откроется по адресу `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

## Перед запуском замените

- [ ] Специалистов, их описания, цены и ссылки на портфолио — сейчас это примеры
- [ ] Цены «от…» в разделе «Что мы делаем»
- [ ] Telegram, почту и телефон (в `index.html` и `config.js`)
- [ ] Реквизиты в `privacy.html` (всё в [квадратных скобках]); текст политики стоит показать юристу
